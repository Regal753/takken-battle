# 宅建バトル Study Quest

宅建業法のオリジナル100問を、1問1敵の4択バトルとして学ぶ公開ベータ版です。

**公開URL:** https://regal753.github.io/takken-battle/

## できること

- 今日の固定10問をブラウザ内で自動生成
- 全100問の一周、章別攻略、弱点狩り
- 正誤、迷い、誤答原因、EXP、宝箱を端末内へ保存
- セーブJSONのバックアップ・読込と、旧ローカル版からの非公開ワンタイム移行
- 25分集中タイマー
- PC・スマートフォン対応

アカウント登録、外部API、サーバーへの学習ログ送信はありません。公開版の進捗は、利用したブラウザの`localStorage`だけに保存されます。別端末へ移る場合は、画面上部の「バックアップ」でJSONを保存し、新しい端末の「読み込む」から引き継げます。

旧ローカル版からの初回移行は、セーブ本体をURLフラグメントに載せて本人のブラウザへ直接渡します。フラグメントはGitHub Pagesへ送信されず、取込時にアドレス欄から除去されます。取込前の公開版セーブも自動バックアップされます。

## ローカル起動

静的ファイルだけで動きます。

```powershell
python -m http.server 8782
```

`http://localhost:8782/`を開いてください。`file://`直開きではなくHTTPサーバーを利用します。

## 検証

```powershell
node .\Audit-TakkenQuestionBank.js
node .\Audit-TakkenRewardSystem.js
node .\scripts\validate-public.mjs
```

GitHub Actionsでも同じ検証を行い、成功した`main`だけをGitHub Pagesへ配信します。
