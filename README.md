# 宅建バトル Study Quest

令和8年度（2026年度）の宅建試験全分野を、本試験配分のオリジナル100問で学ぶ公開ベータ版です。

**公開URL:** https://regal753.github.io/takken-battle/

## できること

- 権利関係28・法令上の制限16・税6・宅建業法40・税以外のその他10
- 学習段階を「①宅建業法」「②法令・税その他」「③全分野」に分け、未学習分野を早過ぎる日課へ混ぜない
- その日の固定10問は、新規を最低6問、翌日以降の要復習を最大4問にして端末内へ固定
- 通常の正解後は毎回「4肢を説明できる／正解したが迷った／切れない肢がある」の理解チェックを必須にし、未回答のまま次問へ進ませない
- 一度の正解では攻略済みにせず、異なる2日で正解して理解チェックも通り、最新の誤答・迷いがない問題だけを「定着」と表示
- コア100接触後は、業法4・権利3・法令2・税その他1の固定比率で、弱点優先・最終接触が古い順の定着10問
- コア100を本試験配分14 / 8 / 3 / 20 / 5に再構成した固定50問確認模試A・B（120分、終了時採点）
- 模試終了後の37点目標・40点安全圏、分野別目標、次の最優先分野、直近3回、誤答解説
- 「今やる」1件だけを先頭に出し、固定10問→公式診断20問→誤答・根拠なし全件の1行化→合計90分を順番に解放
- 本試験10/18のカウントダウン、7/31学習ゲート、毎日90分の4段階クエスト
- RETIO令和7年度から本試験比率に近い20問セットA/B/Cを用意し、3セットで公式50問へ全接触。35分計測、20解答、全問の根拠判定、自動採点、分野別得点、再戦時の前回比を一画面で保存
- RETIO公式の未見過去問を、年度・総得点・4分野・所要時間に分けて端末内へ記録
- 通常解答後と模試誤答レビューから、各問の公式根拠を別タブで確認
- 全分野コア100の一周、章別攻略、弱点狩り
- テーマは「宅建業法」「権利関係」「法令・税その他」の3分野から選択
- 50問確認模試は全100問へ一度接触するまでロックし、未学習問題の答えを模試で先に見ない
- 以前の宅建業法100問は問題本体と既存の解答履歴を保持し、新コア40問の定着とは分けて「解答済み」を表示
- 正誤、迷い、誤答原因、EXP、宝箱を端末内へ保存
- セーブJSONの整合性付きバックアップ・読込、本人用引継ぎリンク、旧ローカル版からの非公開ワンタイム移行
- 更新前rawセーブの自動退避、直前1世代の自動スナップショット、破損時の自動復旧、「直前セーブへ戻す」
- 25分集中タイマー
- PC・スマートフォン対応

アカウント登録、外部API、サーバーへの学習ログ送信はありません。公開版の進捗は、利用したブラウザの`localStorage`だけに自動保存されます。保存キーは従来と同じです。更新時は正規化前のrawセーブを退避し、通常保存では直前1世代を残します。主セーブを読めない場合は破損データを別キーへ退避して直前セーブから復旧します。別端末へ移る場合は、最後に使った端末で「スマホへ渡す」を押し、共有またはコピーした本人用リンクを次の端末で開きます。確認後に取り込むと、その端末でも続きから利用できます。JSONの「バックアップ」→「読み込む」も従来どおり利用でき、新しい書出しには偶発的破損を検出する整合性コードが付きます。旧v1バックアップの読込互換も維持します。

フォームA・Bは既習のコア100を使うため、定着と時間配分の確認用です。初見問題に対する得点の判定は、RETIO公式過去問を開いて別に行い、公式未見過去問スコア台帳へ記録します。同じ年度の再入力に加え、日次の公式20問で一部へ接触した年度も「初見50問」としての登録を拒否し、初見スコアと再演習を混ぜません。過年度問題は法改正により現在法と一致しない場合があるため、年度と現行法を確認してください。

毎日の合格クエストは、固定10問、公式診断20問、誤答・根拠なしの復習、合計90分の4条件です。画面先頭の「今やる」は未完了の先頭1件だけを表示し、完了のたびに次工程へ切り替わります。公式20問はA→B→Cの未完了優先で循環し、Cまで終えると令和7年度50問をすべて接触済みにします。日付を飛ばしてもセットを飛ばしません。全20問の解答に加え、各問で「根拠あり」又は「消去法・勘」を明示しなければ採点できません。誤答又は根拠なしになった全問は、「原因 → 次回ルール」の両側を含む1行を保存するまで復習完了になりません。両方0件なら空の維持ルールを捏造せず自動で次へ進みます。作戦、保存管理、学習モード、学習記録は折りたたみ、スマートフォンでは問題をバトル演出より先に表示します。25分集中タイマーを完走すると、その日の学習時間へ25分を加算します。クエスト、公式20問の解答・根拠判定・得点・復習ルール、学習時間、公式過去問スコアはセーブJSONと本人用引継ぎリンクへ含まれます。

本人用引継ぎリンクと旧ローカル版からの初回移行は、セーブ本体をURLフラグメントに載せて本人のブラウザへ直接渡します。フラグメントはGitHub Pagesへ送信されず、取込時にアドレス欄から除去されます。取込前の公開版セーブも自動バックアップされます。引継ぎリンクには学習進捗が含まれるため、他人へ送らず、使用後は共有先から削除してください。

## ローカル起動

静的ファイルだけで動きます。

```powershell
python -m http.server 8782
```

`http://localhost:8782/`を開いてください。`file://`直開きではなくHTTPサーバーを利用します。


GitHub Actionsでも同じ検証を行い、成功した`main`だけをGitHub Pagesへ配信します。
Pages配信後は公開HTMLを最大12回再取得し、模試A/Bボタンと配信バージョンが実際に反映されたことまで自動確認します。

`Audit-TakkenQuestionQuality.js`は、正解肢と○×解説の一致、個数問題の正しい肢数、公式根拠ドメイン、同文選択肢の矛盾、設問の類似重複、正解肢の長さ・絶対表現による手掛かり、模試内の正解位置連続を監査します。

`Audit-TakkenFullExamUi.cjs`はChromeを使うローカル実ブラウザ監査です。宅建業法だけの固定10問、正解後の必須理解チェック、理解未選択時の進行拒否、一度正解を定着扱いしないこと、「今やる」の4工程遷移、公式20問の35分計測・20解答・全問根拠判定・根拠未選択時の採点拒否・自動採点・複数復習ルール保存、スマートフォンでの問題先行配置、全100問接触前の模試ロック、接触後の定着10問、模試50問、途中の正誤非表示、目標付き終了後採点、履歴、再読込を通しで確認します。`Audit-TakkenOfficialDrill.js`はA/B/Cの各20問、分野配分、公式解答、50問全接触を検算します。`Audit-TakkenSaveStore.js`は更新前退避・破損復旧・直前復元を、`Audit-TakkenRealSaveCompatibility.cjs`は公開しない実バックアップを使って主要進捗の意味的完全保持を確認します。合格作戦パネルは、公式未見過去問の入力・合計検算・接触済み年度の選択禁止と保存側拒否・端末保存・折りたたみ構造・PC/スマートフォン幅を別途実ブラウザで確認します。
