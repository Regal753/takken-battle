# 2026法改正ノックの内容と検証

2026年4月1日現在施行の法令を基準とする、オリジナル40問・160肢。2024〜2026年の改正で、過去問だけでは反復しにくい新旧ルール・適用日・母数・主体・金額の境界を練習する。教材本文・公式過去問本文の転載ではない。法的確認日: 2026-10-14。

[RETIOの試験概要](https://www.retio.or.jp/exam/exam_detail/)は試験年度4月1日現在施行の法令を出題根拠としている。基準日後の改正、当年統計、出題可能性の断定は収録しない。
