# 宅建バトル Study Quest

令和8年度（2026年度）の宅建試験全分野を、本試験配分のオリジナル・コア100問で学ぶ公開ベータ版です。市販テキストの全3分冊・4章・45単元に対応した読後演習124問を、本文ページ単位で選べます。

**公開URL:** https://regal753.github.io/takken-battle/

## できること

- 権利関係28・法令上の制限16・税6・宅建業法40・税以外のその他10
- Chapter 01（第1分冊）11単元44問、Chapter 02（第2分冊）21単元44問、Chapter 03（第3分冊）7単元18問、Chapter 04（第3分冊）6単元18問を本文ページと対応させ、各単元を読んだ直後に最低2問を解ける
- 読後演習専用の補助24問を追加しつつ、コア100・固定50問確認模試の構成は変更しない
- 全124問の496肢すべてに具体的な判定理由を持たせ、解答後は「判断軸→この問題への当てはめ→間違いやすい境界→次に再現する一文」の順で理解を組み立てる
- 学習段階を「①宅建業法」「②第2分冊・権利関係」「③法令・税その他」「④全分野」に分け、未学習分野を早過ぎる日課へ混ぜない
- その日の固定10問は、新規を最低6問、翌日以降の要復習を最大4問にして端末内へ固定
- 通常の正解後は毎回「4肢を説明できる／正解したが迷った／切れない肢がある」の理解チェックを必須にし、未回答のまま次問へ進ませない
- 一度の正解では攻略済みにせず、異なる2日で正解して理解チェックも通り、最新の誤答・迷いがない問題だけを「定着」と表示
- コア100接触後は、業法4・権利3・法令2・税その他1の固定比率で、弱点優先・最終接触が古い順の定着10問
- コア100を本試験配分14 / 8 / 3 / 20 / 5に再構成した固定50問確認模試A・B（120分、終了時採点）
- 模試終了後の37点目標・40点安全圏、分野別目標、次の最優先分野、直近3回、誤答解説
- 「今やる」1件だけを先頭に出し、固定10問→公式診断20問→誤答・根拠なし全件の1行化→合計90分を順番に解放
- 本試験10/18のカウントダウン、7/31学習ゲート、毎日90分の4段階クエスト
- RETIO令和7年度から本試験比率に近い20問セットA/B/Cを用意し、3セットで公式50問へ全接触。スマートフォンでも1問ずつ解答し、35分計測、全問の根拠判定、自動採点、分野別得点、再戦時の前回比を保存
- RETIO公式50問は2020・2021年の10月／12月試験を別試験として管理し、初見10回と14日後の再試験3回を120分計測・1問入力・自動採点
- 120分以内・自動採点・2026年4月1日現在法との照合済み記録だけで、直近3回の平均と最低点から「合格域」「安定40」を判定
- 通常解答後と模試誤答レビューから、各問の公式根拠を別タブで確認
- 全分野コア100の一周、章別攻略、弱点狩り
- テーマは第1分冊「宅建業法」、第2分冊「権利関係」、第3分冊の「法令上の制限」「税・その他」という全4章・45単元から選択
- 50問確認模試は全100問へ一度接触するまでロックし、未学習問題の答えを模試で先に見ない
- 以前の宅建業法100問は問題本体と既存の解答履歴を保持し、新コア40問の定着とは分けて「解答済み」を表示
- 正誤、迷い、誤答原因、EXP、宝箱を端末内へ保存
- 報酬・手付・違約金・保全・印紙税を24問で回す「計算・金額特訓」。全問に途中式を表示し、誤答と「迷った」を自動で再出題
- セーブJSONの整合性付きバックアップ・読込、本人用引継ぎリンク、旧ローカル版からの非公開ワンタイム移行
- 更新前rawセーブの自動退避、直前1世代の自動スナップショット、破損時の自動復旧、「直前セーブへ戻す」
- 取込前・復元前・破損退避は種別ごとに直近3世代へ整理し、JSONバックアップ日時と保存領域80%以上の警告を表示
- 25分集中タイマー
- PC・スマートフォン対応

アカウント登録、外部API、サーバーへの学習ログ送信はありません。公開版の進捗は、利用したブラウザの`localStorage`だけに自動保存されます。保存キーは従来と同じです。更新時は正規化前のrawセーブを退避し、通常保存では直前1世代を残します。主セーブを読めない場合は破損データを別キーへ退避して直前セーブから復旧します。別端末へ移る場合は、最後に使った端末で「スマホへ渡す」を押し、共有またはコピーした本人用リンクを次の端末で開きます。確認後に取り込むと、その端末でも続きから利用できます。JSONの「バックアップ」→「読み込む」も従来どおり利用でき、新しい書出しには偶発的破損を検出する整合性コードが付きます。旧v1バックアップの読込互換も維持します。

フォームA・Bは既習のコア100を使うため、定着と時間配分の確認用です。初見力はRETIO公式50問を、試験回別の解答シートで120分計測して判定します。2020・2021年の10月試験と12月試験は別IDです。日次20問で接触済みの試験回は初見測定に使わず、再試験は初見から14日後に1回だけ解放します。紙で解いた旧得点は参考記録として残せますが、自己申告のため安定度には算入しません。過年度問題は法改正により現在法と一致しない場合があるため、現在法の照合完了なしでは測定記録へ算入しません。

毎日の合格クエストは、固定10問、公式診断20問、誤答・根拠なしの復習、合計90分の4条件です。画面先頭の「今やる」は未完了の先頭1件だけを表示し、完了のたびに次工程へ切り替わります。前日以前の未復習があれば、当日の固定10問後・新しい公式20問前へ繰り越します。公式20問はA→B→Cの未完了優先で循環し、1画面1問で解答します。全問で「根拠あり」又は「消去法・勘」を明示しなければ採点できません。2025年4月1日基準の歴史問題なので、15点・16点は原問換算の訓練値であり合格安定度へは算入しません。誤答又は根拠なしになった全問は、誤答原因を選び、「原因 → 次回に具体的に何を見る・書く」の1行を保存するまで復習完了になりません。対象0件なら空の維持ルールを捏造せず自動で次へ進みます。

本人用引継ぎリンクと旧ローカル版からの初回移行は、セーブ本体をURLフラグメントに載せて本人のブラウザへ直接渡します。フラグメントはGitHub Pagesへ送信されず、取込時にアドレス欄から除去されます。取込前の公開版セーブも自動バックアップされます。引継ぎリンクには学習進捗が含まれるため、他人へ送らず、使用後は共有先から削除してください。

## ローカル起動

静的ファイルだけで動きます。

```powershell
python -m http.server 8782
```

`http://localhost:8782/`を開いてください。`file://`直開きではなくHTTPサーバーを利用します。
