# 宅建バトル Study Quest

令和8年度（2026年度）の宅建試験全分野を、本試験配分のオリジナル・コア100問で学ぶ公開ベータ版です。市販テキストの全3分冊・4章・45単元に対応した読後演習124問と、別枠の実践バリエーション180問を収録しています。

**公開URL:** https://regal753.github.io/takken-battle/

## 理解設計の根拠

- [RETIOの試験概要](https://www.retio.or.jp/exam/exam_detail/)に合わせ、50問・四肢択一で近い規則と例外を判別する力へ接続する。法令基準日は試験年度の4月1日として扱う
- [RETIO公式過去問](https://www.retio.or.jp/exam/past_ques_ans/other/)は基礎一周後の測定へ回し、法改正で現在法と結論が変わり得る問題を基礎説明へ混ぜない
- Chiほかの[自己説明研究](https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog1803_3)を踏まえ、モデル解説を「見る条件→使う根拠→当てはめ」に分け、任意のミス原因記録で自分の誤認も残せるようにする
- KarpickeとRoedigerの[検索練習研究](https://doi.org/10.1126/science.1152408)とButlerの[転移研究](https://pubmed.ncbi.nlm.nih.gov/20804289/)を踏まえ、本問への解答と翌日以降の再解答を検索練習にし、別事例は各問へ強制せず単元別の実践4問へ分ける
- ButlerとRoedigerの[フィードバック研究](https://pubmed.ncbi.nlm.nih.gov/18491500/)を踏まえ、解答直後に正解だけでなく解き方・全肢理由・誤認境界を返す

## できること

- 権利関係28・法令上の制限16・税6・宅建業法40・税以外のその他10
- Chapter 01（第1分冊）11単元44問、Chapter 02（第2分冊）21単元44問、Chapter 03（第3分冊）7単元18問、Chapter 04（第3分冊）6単元18問を本文ページと対応させ、各単元を読んだ直後に最低2問を解ける
- 読後演習専用の補助24問を追加しつつ、コア100・固定50問確認模試の構成は変更しない
- 全124問の496肢すべてに具体的な判定理由を持たせ、解答直後に「見る条件→使う根拠→この問題への当てはめ」の3段階で解き方を示す
- 1問ごとの15字入力・判断軸4択・転用ミニ問は置かない。正誤を押せば解き方、正解肢、全肢理由、公式根拠がすぐ開き、そのまま次問へ進める
- 別事例での応用は全45単元に4問ずつ用意した実践バリエーション180問へ分離し、読後問題の途中へ割り込ませない
- 全45単元に4問ずつ、単一選択2問・組合せ1問・個数1問の実践バリエーション180問。各肢に元問題の事例前提を付け、単元別4問と分野別4／10／20／45問セット（宅建業法は最大44問）、正答位置均等、誤答・迷いの再出題に対応
- 基礎一周中は先頭の「宅建業法を10問で振り返る」から1操作で任意実践へ入れる。学習段階に合わせて宅建業法・権利関係・法令／税その他を引き継ぎ、誤答・迷い、未接触、既出の順で出題する
- 宅建業法は「基礎44問の定着」「変形132問の長期定着」「別試験回・別学習日の公式50問で業法20/20を3回」の3条件を専用パネルで追う。変形132問は、基礎44問から抽出した176肢と、2024〜2026年改正・免許・供託・35条／37条・8種制限・監督罰則・犯罪収益移転防止法・住宅瑕疵担保履行法を補う68肢の合計244論点を全て出題する
- 基礎44問と変形132問は、誤答／迷い→期限到来→未接触→学習中→定着→長期定着の順に出題する。根拠を言えた正答だけを日をまたいで1／3／7／14／30日後に確認し、同日反復や期日前反復、単なる試行回数では定着にしない。30日後の最終再現まで成功した問題だけを長期定着とする
- 任意実践の途中又は完了状態は再読込後もパネルを自動で再表示し、完了後は同条件で続行、分野・問題数の変更、学習画面への復帰を選べる
- 基礎一周は「本文を読む→読後2〜4問→次の未接触単元」を優先する。同じ単元の実践4問は通行証にせず、復習・混合実践の別レーンとして残す
- 1単元に問題が多い場合も読後問題を2〜4問ずつに分割し、15問の単元を一度に要求しない。単元全問への接触は累積で判定する
- 学習段階を「①宅建業法」「②第2分冊・権利関係」「③法令・税その他」「④全分野」に分け、45単元の読後問題が終わるまで未学習分野の公式問題をロックする
- 基礎一周後の復習10問は、新規を最低6問、要復習を最大4問にして端末内へ固定する。通常画面では一行へ折りたたみ、問題本文の表示領域を優先する
- 通常解答後は「こう解く」と全肢理由を即時表示し、追加問題や文章入力で次問をロックしない
- 誤答は自動で弱点へ保存する。誤認した肢・原因タグ・一言メモは任意で、残せば入力ごとに自動保存する
- 一度の正解では攻略済みにせず、異なる2日で正答し、最新の誤答・「勘・迷い」がない問題だけを「定着」と表示
- コア100接触後は、業法4・権利3・法令2・税その他1の固定比率で、弱点優先・最終接触が古い順の定着10問
- コア100を本試験配分14 / 8 / 3 / 20 / 5に再構成した固定50問確認模試A・B（120分、終了時採点）
- 模試終了後の37点目標・40点安全圏、分野別目標、次の最優先分野、直近3回、誤答解説
- 「今やる」1件だけを先頭に出し、基礎一周中は読む単元・読後問題から次の1件だけを表示。翌日復習と実践は別レーンに残し、基礎一周後は復習10問→公式診断20問→誤答・根拠なし全件の1行化→合計90分を順番に解放
- 本試験10/18のカウントダウンと、期限ではなく実績で開く「45単元・読後124問」の基礎ゲート
- RETIO令和7年度から本試験比率に近い20問セットA/B/Cを用意し、3セットで公式50問へ全接触。スマートフォンでも1問ずつ解答し、35分計測、全問の根拠判定、自動採点、分野別得点、再戦時の前回比を保存
- RETIO公式50問は2020・2021年の10月／12月試験を別試験として管理し、初見10回と14日後の再試験3回を120分計測・1問入力・自動採点する。満点圏の公式証拠には、アプリ内で未接触だった別試験回を別学習日に開始し、全50問の解答から再計算した宅建業法20/20だけを使う
- 120分以内・自動採点・2026年4月1日現在法との照合済み記録だけで、直近3回の平均と最低点から「合格域」「安定40」を判定
- 通常解答後と模試誤答レビューから、各問の公式根拠を別タブで確認
- 全124問に条文又は論点単位の根拠位置を表示し、令和8年度基準日の管理業者管理者方式・標識の大きさ・森林法令・港湾法関係改正を国土交通省資料から確認する
- 全分野コア100の一周、章別攻略、弱点狩り
- テーマは第1分冊「宅建業法」、第2分冊「権利関係」、第3分冊の「法令上の制限」「税・その他」という全4章・45単元から選択
- 「単発で解くテーマ」と「日課の学習範囲」を別ラベルで明示。テーマ選択はその単元の全問だけを完走し、途中で復習10問へ切り替えず、日次の固定計画も変更しない
- 公式20問・公式50問・50問確認模試は45単元の読後124問へ一度接触するまでロックし、未学習問題の答えを測定で先に見ない
- 以前の宅建業法100問は問題本体と既存の解答履歴を保持し、新コア40問の定着とは分けて「解答済み」を表示
- 正誤を押した瞬間に、迷い、任意の誤答原因、EXP、宝箱を同じ端末のブラウザ内へ自動保存
- 報酬・手付・違約金・保全・印紙税を24問で回す「計算・金額特訓」。上部から直接開始・再開でき、全問に途中式を表示し、誤答と「迷った」を自動で再出題。途中／完了reloadでも自動復帰し、もう一周しても累計履歴を保持
- セーブJSONの整合性付きバックアップ・読込、本人用引継ぎリンク、旧ローカル版からの非公開ワンタイム移行
- 更新前rawセーブの自動退避、直前1世代の自動スナップショット、破損時の自動復旧、「直前セーブへ戻す」
- 取込前・復元前・破損退避は種別ごとに直近3世代へ整理し、JSONバックアップ日時と保存領域80%以上の警告を表示
- 25分集中タイマー
- PC・スマートフォン対応
- 解答後は本文末尾と画面下部の両方に次問ボタンを出し、390px幅では下部操作の半分以上を次問へ割り当てる

アカウント登録、外部API、サーバーへの学習ログ送信はありません。公開版は解答・迷い・任意メモの変更ごとに、利用したブラウザの`localStorage`へ自動保存します。保存先はその端末・そのブラウザ内だけで、クラウド同期ではありません。保存キーは従来と同じです。更新時は正規化前のrawセーブを退避し、通常保存では直前1世代を残します。主セーブを読めない場合は破損データを別キーへ退避して直前セーブから復旧します。別端末へ移る場合は、最後に使った端末で「スマホへ渡す」を押し、共有またはコピーした本人用リンクを次の端末で開きます。確認後に取り込むと、その端末でも続きから利用できます。JSONの「バックアップ」→「読み込む」も従来どおり利用でき、新しい書出しには偶発的破損を検出する整合性コードが付きます。旧v1バックアップの読込互換も維持します。

フォームA・Bは既習のコア100を使うため、定着と時間配分の確認用です。初見力はRETIO公式50問を、試験回別の解答シートで120分計測して判定します。2020・2021年の10月試験と12月試験は別IDです。日次20問、公式PDF、手入力記録で接触済みの試験回は初見測定に使わず、再試験は初見から14日後に1回だけ解放します。公式PDFは露出台帳を端末へ保存してから開き、開始条件を満たさない場合は開きません。紙で解いた旧得点は参考記録として残せますが、自己申告のため安定度や満点圏の証拠には算入しません。過年度問題は法改正により現在法と一致しない場合があるため、2026年4月1日基準との照合完了なしでは測定記録へ算入しません。「満点圏」はこのアプリ内の学習証拠から導く目安で、改変されたJSONを暗号学的に証明する仕組みではありません。

基礎一周中の「今やる」は、読む単元と読後2〜4問から未完了の1件だけを表示し、完了後は次の未接触単元へ進みます。読後問題では、解答直後に「こう解く」と全肢理由を読み、そのまま次問へ進みます。別事例は読後問題へ毎回挟まず、実践バリエーションの別レーンで扱います。1単元の読後問題が4問を超える場合は、残数を保ったまま2〜4問単位で次の組へ進みます。45単元・124問への接触が終わるまでは公式演習と模試を解放しません。

基礎一周後の毎日の合格クエストは、復習10問、公式診断20問、誤答・根拠なしの復習、合計90分の4条件です。完了のたびに先頭の1件を再選定します。前日以前の未復習があれば、新しい公式20問より先へ繰り越します。公式20問はA→B→Cの未完了優先で循環し、1画面1問で解答します。全問で「根拠あり」又は「消去法・勘」を明示しなければ採点できません。2025年4月1日基準の歴史問題なので、15点・16点は原問換算の訓練値であり合格安定度へは算入しません。誤答又は根拠なしになった全問は、誤答原因を選び、「原因 → 次回に具体的に何を見る・書く」の1行を保存するまで復習完了になりません。対象0件なら空の維持ルールを捏造せず自動で次へ進みます。

本人用引継ぎリンクと旧ローカル版からの初回移行は、セーブ本体をURLフラグメントに載せて本人のブラウザへ直接渡します。フラグメントはGitHub Pagesへ送信されず、取込時にアドレス欄から除去されます。取込前の公開版セーブも自動バックアップされます。引継ぎリンクには学習進捗が含まれるため、他人へ送らず、使用後は共有先から削除してください。
