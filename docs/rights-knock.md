# 権利関係 根拠ノック

既存の権利関係44問に、法令ノックと同じ専用入口を追加する。

- 弱点・期限到来・未接触を優先する20問。
- 未接触から最大20問を選ぶモードと、全44問の総点検。
- 44問を重複なく16テーマへ分けたテーマ別練習。
- 解答前の「根拠を言える／迷い／ヤマ勘」。迷い・勘による正解も同じセットで再出題する。
- 接触・根拠あり正答・別日定着・ヤマ勘累計と、テーマごとの要再戦表示。

問題ID・正誤・各肢解説・法令基準・保存schemaは変更しない。既存の科目別練習と `practicalDrill.history` を共有する。旧権利44問セットの解答フローは維持し、新しい入口で始めたセットだけ解答前の手応えを必須にする。開始前に他の進行中セットがあれば、その保存位置へ戻る。

`Audit-TakkenRightsKnockUi.cjs` で20問の選問、誤答・迷い・勘の再出題、肢順変更、保存再開、他科目の履歴保持、16テーマ全44問の到達、同日反復の定着非昇格、旧権利セットを検証する。1280/390/320pxのパネル画像を `output/playwright/rights-knock/` へ保存する。
